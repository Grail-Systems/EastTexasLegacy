# East Texas Legacy Coalition

The public website for the East Texas Legacy Coalition (ETLC): **https://easttexaslegacy.org**

ETLC is a grassroots coalition out of Angelina County, Texas, founded by Fawn Elizabeth Zion. It files public records requests about data centers, crypto mines and power plants over the Carrizo-Wilcox Aquifer and publishes what comes back.

## What's here

- `index.html` is the homepage. Every figure on it cites its source on the page.
- `ercot-tracker/` lists the 136 East Texas projects in ERCOT's April 2026 Generator Interconnection Status report, plus Angelina County appraisal records for the related parcels. Threat levels there are ETLC's own ratings.
- `amp-z-investigation.html`, `aquifer-defense.html` and `secure-intake.html` now redirect to the live tools.

## The live tools

The Aquifer Defense Grid, the records request tracker, the Wall of Shame and the Powered Land report live in the [carrizo_wilcox_aquifer](https://github.com/Grail-Systems/carrizo_wilcox_aquifer) repository at grailsystems.io.
